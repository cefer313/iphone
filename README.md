# Baxışını dəyiş

Motivasiya və şəxsi inkişaf saytı (AZ / RU / EN).

## Fayllar
- `index.html` — səhifə strukturu
- `css/style.css` — dizayn
- `js/i18n.js` — bütün mətnlər və tərcümələr (mətni burada dəyişin)
- `js/main.js` — dil dəyişmə, menyu, günün fikri, əlaqə formu

## Baxmaq
`index.html` faylını brauzerdə açın. Pulsuz yayımlamaq üçün GitHub Pages istifadə edə bilərsiniz
(Settings → Pages → branch seçin).
